# Chainlink DKG (smdkg)

This repository implements a Distributed Key Generation (DKG) protocol for the Chainlink Network. It generates a keypair in a secure, decentralized way such that no single party ever learns the private key.

Please see the [Chainlink DKG whitepaper](https://research.chain.link/dkg.pdf) for a detailed protocol description.

This library is used in production.
